# 09: Sound candidates

**What to build:** CC0 candidates for the four ambience loops (waves, birds, town, night insects) and the three UI
sounds (tap, a building landing, collecting a reward), ready for the user to listen to. Spec: "Sound" (sources).

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Two to four candidates per sound from Kenney's audio packs (UI) and OpenGameArt or Freesound filtered to CC0
      (ambience), each with its link and license; Freesound downloads that need the user's sign-in are listed for the
      user to fetch.
- [ ] Downloads go into their own new directories under the ignored asset folders, treated as untrusted; nothing
      inside them is run.
- [ ] A small local listening page (not shipped) plays each candidate side by side, looping the ambience ones.
